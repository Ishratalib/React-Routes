# React Routes

React Routes is a simple React application built to practice and demonstrate client-side routing using React Router. It includes multiple pages, nested routes, dynamic product routes, protected routes, and a custom 404 page.

## Live Demo

https://react-routes-project.netlify.app/

## Technologies Used

* React
* React Router DOM
* Vite
* JavaScript
* CSS

## Features

* Home, About, Contact, and Login pages
* Product listing page
* Dynamic product detail routes
* Protected Dashboard route
* React Router navigation
* Nested routing with `Outlet`
* Dynamic routing using URL parameters
* Navigation using `Link`
* Custom 404 Not Found page
* Responsive Vite setup
